# Política de Segurança do PortfolioHUB

## Acesso e usuários
- Autenticação em dois fatores obrigatória para o proprietário do repositório.
- Colaboradores recebem a menor permissão necessária (Write); Admin apenas para o proprietário.
- O acesso é revisado a cada entrega e removido quando não for mais necessário.

## Código e conteúdo
- Nenhuma senha, token ou chave de API deve ser enviada ao repositório.
- Alterações na branch main só entram por Pull Request com revisão.

## Dados
- Documentos com dados pessoais ou sigilosos não devem ser publicados no repositório; usar link restrito do Google Drive.

## Reporte de problemas
Se encontrar uma falha de segurança, avise o proprietário em privado antes de divulgar.
