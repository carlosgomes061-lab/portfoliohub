# Como contribuir com o PortfolioHUB

1. Crie uma branch a partir da main (ex.: feature/nome-da-alteracao).
2. Faça commits pequenos, com mensagens descritivas.
3. Abra um Pull Request descrevendo o que mudou.
4. Aguarde a revisão de outra pessoa antes do merge.
5. Nunca envie senhas, tokens ou dados sigilosos.
